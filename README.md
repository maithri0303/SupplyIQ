# SupplyIQ — Demand, Inventory & Supply Planning

SupplyIQ is a synthetic-data planning control tower built for the ORYVA AI assignment. It connects forecast demand, inventory, supplier constraints, lead times, shortage prioritization and mitigation trade-offs in an explainable workflow.

## What is included
- Streamlit interactive planning dashboard (executive overview, demand/inventory, shortage queue, mitigation planner, data governance)
- Deterministic synthetic data generator (seed `20261022`)
- Starter and full-scale generation commands
- Entity data dictionary
- Validation script and separate ground-truth output
- CSV exports from the dashboard

## Quick start (Windows)
```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python generator.py --scale starter
streamlit run app.py
```
Open the local Streamlit URL shown in the terminal.

## Generate full assignment-scale data
```powershell
python generator.py --scale full --out data/full
python validate.py
```
The full assignment target is 3,000 SKUs, 50 locations, 52 weeks, 500 suppliers and 10,000 inbound orders. Adjust the generator scale parameters in `full_scale()` when preparing the final full-volume run. Full-scale demand can be large; use a machine with sufficient RAM and disk.

## Data and business logic
- Demand is generated by SKU-location-week with stochastic baseline variation and occasional demand spikes.
- Inventory includes starting on-hand and inbound receipts.
- Projected balance is calculated cumulatively from on-hand + inbound - forecast demand.
- Shortage quantity is the positive gap between safety stock and projected balance.
- Priority score uses shortage units × SKU unit cost.
- Mitigation options include expedite and transfer/substitute alternatives with estimated cost, recovery and service-day trade-off.
- Five labeled exception types are recorded in `ground_truth.csv` as synthetic scenarios. Ground truth must be kept separate from input features.

## Required entities
SKU, Location, ForecastDemand, Inventory, Supplier, SupplierCapacity, LeadTime, PurchaseOrder, ProductionPlan, Shortage and MitigationOption.

## Reproducibility
The default seed is fixed at `20261022`. Run the generator twice with the same seed and compare output checksums:
```powershell
python generator.py --scale starter --out data/run_a
python generator.py --scale starter --out data/run_b
```
For checksum comparison:
```powershell
Get-FileHash data/run_a/*.csv
Get-FileHash data/run_b/*.csv
```

## Important prototype note
This is a polished, runnable starter implementation. Before final submission, run full-scale generation and validation on your machine, inspect all five edge-case detection paths, ensure the exact 500-supplier and 10,000-inbound-order volumes, and include the resulting validation summary in the public repository. Never present synthetic outputs as real company data.
